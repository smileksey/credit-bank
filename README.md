# Приложение "Кредитный банк"
### Бэкенд-приложение - прототип небольшого банка, основанное на микросервисной архитектуре.

Осуществляет рассчет параметров кредита, исходя из данных клиента.

По запросу клиента осуществляется прескоринг и расчет 4 кредитных предложений. Клиент выбирает одно из предложений и отправляет свои полные данные. Происходит скоринг и расчет всех условий кредита, либо принимается решение об отказе. На каждом этапе клиент получает уведомления о ходе сделки по e-mail. 

Приложение включает 5 микросервисов: `calculator`, `deal`, `statement`, `dossier`, `gateway`. Взаимодействие между микросервисами осуществляется с помощью REST и Kafka. Взаимодействие с клиентом - с помощью REST API через микросервис `gateway`. 
#### Стэк:
- Java 17
- SpringBoot 2.7.18
- PostgreSQL
- Spring Data JPA
- Liquibase
- Swagger
- Kafka
- Junit
- Lombok
- Docker
