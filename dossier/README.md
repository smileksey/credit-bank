## Микросервис "dossier"

В обязанности данного микросервиса входят: 
- Обработка сообщений из Kafka от МС Сделка на каждом шаге, который требует отправки письма на почту клиенту.
- Отправка этих электронных писем.

МС Сделка выступает в роли издателя (producer), МС Досье - в роли подписчика (consumer).

В Kafka создано 6 топиков, соответствующих темам, по которым необходимо направить письмо на почту клиенту. На каждый из этих топиков подписан МС Досье:

- `finish-registration` - уведомление о необходимости завершить регистрацию и отправить полные данные.
- `create-documents` - уведомление о необходимости отправить запрос на формирование документов.
- `send-documents` - уведомление о готовности документов и необходимости отправки запроса на их подписание.
- `send-ses` - уведомление о необходимости подписания документов с помощью кода ПЭП, который указывается в письме.
- `credit-issued` - уведомление об успешном оформлении кредита.
- `statement-denied` - уведомление об отказе в кредите.

После обработки сообщения из топика `send-documents` МС Досье отправлет PUT-запрос в МС Сделка на http://localhost:8081/deal/admin/statement/{statementId}/status для обновления статуса заявки (`Statement`).
